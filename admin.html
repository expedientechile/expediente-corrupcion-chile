Administración del expediente

Ingresa con un token de GitHub. Solo quien tenga permiso de escritura en el repositorio puede guardar cambios.

El token se guarda solo mientras esta pestaña esté abierta. Nunca queda escrito en el código ni en el sitio.
¿Cómo creo el token?
  1. En GitHub: tu foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Resource owner: tu cuenta. Repository access: Only select repositories y elige solo este repositorio.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Fija una fecha de vencimiento (por ejemplo 90 días), genera el token y cópialo aquí.

Importar casos desde CSV

El archivo debe tener una fila de encabezados con los mismos nombres de campo del JSON (ver la plantilla). Acepta separador coma o punto y coma, y codificación UTF-8.

Si el id de una fila ya existe, ese caso se actualiza; si no existe, se agrega como caso nuevo (y entonces debe traer todos los campos obligatorios). En los casos existentes, las columnas ausentes y las celdas vacías no modifican nada; para borrar un dato usa el formulario.
